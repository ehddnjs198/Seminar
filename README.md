# SW 개발 기초 세미나

C# / WPF (.NET 8) · Visual Studio 2022

| 폴더 | 내용 |
|---|---|
| `01_PhoneBook` | 전화번호부 – 추가 · 삭제 · 검색 · 전시 |
| `02_ChatProgram` | 채팅 – SocketBase 상속 TCP / UDP 클래스 |
| `03_BmpMaker` | 실행 시 Red · Green · Blue `.bmp` 파일 생성 |
| `04_SerialGps` | USB GPS 시리얼 수신 → NMEA 파싱 → WGS84 · UTM 전시 |
| `PPT` | 세미나별 발표 자료 |

`Seminar.sln`을 열고 실행할 프로젝트를 **시작 프로젝트로 설정** 후 F5.
